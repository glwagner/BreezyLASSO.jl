# Results

Figures and lightweight summaries from committed runs. Each run directory in `output/`
(not versioned) carries a `provenance.toml`; the corresponding record is copied here as
`<run>_provenance.toml` next to its figures. `summary.md` is regenerated by
`analysis/plot_results.jl` from the runs listed in the table.

| run | configuration | status |
|---|---|---|
| `covert_public_bin_one_moment` | Covert-public-bin development benchmark, 1M control, 256×256×192 (Covert grid, Δz = 10 m to 1.5 km), Float32, fixed Δt = 0.5 s, 6 h | complete (Slurm job 859, 75 min on one A100) |
| P3-N75, P3-aer2 | same inputs; see the README section *Rain-number runaway in the 10-m surface layer* for why the Covert-grid members failed and how the P3 members are being rerun | in progress |

Every run here uses the public Covert et al. (2022) inputs and is a development benchmark,
not an official LASSO-ENA reproduction (that needs the restricted `samin` archive).
